ROXY BROWSER DEMO

浏览器会话

导入账号，使用指定代理打开 Roxy；登录状态保存在本机文件。

运行配置

所有保留配置均在此展示。保存后，新窗口使用新配置；已打开窗口沿用打开时的配置。

固定运行策略

导入账号

每行 邮箱----密码----2FA密钥，也支持 -- 和 ====；重复邮箱更新凭据。

账号凭据、代理及会话保存在此项目的 data 目录。

账号 0

先设置代理，再打开或刷新。需要额外验证时，直接在 Roxy 窗口中完成。

账号 / 代理会话窗口状态操作

还没有账号，先导入一行开始。

关闭网页不会关闭 Roxy。使用“关闭窗口”会先保存会话；直接关闭浏览器时保留最近有效快照。

账号代理

支持供应商格式和 HTTP、HTTPS、SOCKS5、SOCKS5H URL；保留原用户名及 SID。
